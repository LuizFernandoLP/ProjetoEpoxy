How to use

  1. Start the rear camera.
  2. Tap Set floor area.
  3. Tap the four corners of the visible floor, clockwise.
  4. Choose a preset or upload a texture.
  5. Adjust strength, gloss, and scale.

Tip: select the floor boundary, not the baseboards. The four-point overlay is fixed to the camera view, so reset it if you move the phone.

Preview only. Actual epoxy color and reflectivity vary with lighting, preparation, and application.
